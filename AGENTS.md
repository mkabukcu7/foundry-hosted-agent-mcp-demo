# Agent Development

This project was built with the microsoft-foundry skill. Before working on or
answering questions about Foundry agents, read the microsoft-foundry skill
first. If you are in VS Code, read the vscode-microsoft-foundry skill first.

The deployable hosted-agent source is in `agent/`. Keep its Responses protocol,
model configuration, MCP integration, and tests aligned. Never provision,
deploy, or delete Azure resources without explicit approval.
